# Security policy

## Reporting a vulnerability

Please do not report security issues in a public issue.

Use GitHub's private vulnerability reporting form for this repository:

<https://github.com/dummy3ye/arinaholic/security/advisories/new>

Include the affected URL or file, the impact, and steps to reproduce if
possible. You should receive an acknowledgement once the report has been
reviewed.

## Supported versions

Security fixes are applied to the latest deployment of `master`. Older commits
and preview deployments are not maintained.
